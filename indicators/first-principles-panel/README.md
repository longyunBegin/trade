# 第一性原理面板（TradingView 指标）

代码：[`panel.pine`](./panel.pine)

## 为什么做这个

大多数指标（RSI、MACD、KDJ、布林带）都是从价格算出来的二次加工，信息和价格本身大量重叠，叠多了只会更乱。这个面板只看三样最原始的东西：**价格、成交量、和板块比的相对表现**。点开任意代码，一眼看清趋势、力量、位置和风险。

它是用来看清「现在是什么状态」的，不预测下一步涨跌。

## 图上画了什么

- **三条均线**：MA20（黄）、MA50（橙）、MA200（红，加粗）
- **两条阶梯线**：最近 20 根 K 线的最高点（紫，阻力）和最低点（绿，支撑）
- **右下角摘要表**：用大白话写出下面六项

## 六项读法

### 1. 均线
对应代码：`maFast / maMid / maSlow`、`posTxt`、`alignTxt`

- **位置**：价格在三条均线上方，说明短、中、长期买入者平均都在赚钱，趋势偏强；三线都在价格上方则相反；夹在中间就是「夹在均线间」。
- **排列**：MA20 > MA50 > MA200 叫「多头排列」，短期涨得比长期快，趋势健康；完全反过来叫「空头排列」；其他情况叫「均线纠缠」，没有明确方向。

### 2. 结构
对应代码：`prevHH / prevLL`、`structTxt`

拿今天收盘价和之前 20 根 K 线的最高、最低点比：
- **突破近高**：买方把价格推出了原来的区间
- **跌破近低**：卖方占上风
- **区间内**：还在原范围里来回晃

### 3. 量能
对应代码：`volMa`、`volRatio`

今天成交量 ÷ 20 日平均成交量。大于 1 是放量，小于 1 是缩量。要配合价格看：上涨放量说明有真金白银在推，上涨缩量说明力量偏弱；突破时放量，可信度更高。

### 4. ATR
对应代码：`atrVal = ta.atr(14)`

最近 14 天平均每天的波动幅度（单位是价格）。比如 ATR 是 12.91，就是这只股票平时一天大约晃动 12.91 美元。

主要用来定止损：止损比 1 个 ATR 还近，很容易被正常波动扫掉，常见做法是放在 1.5 到 2 个 ATR 之外。**它不判断方向。**

### 5. 相对强弱
对应代码：`benchClose`、`rs`、`rsMa`、`rsTxt`

计算「个股价格 ÷ 基准价格」，再和这个比值的 20 日均值比。高于均值就是「相对基准偏强」，说明最近跑赢了板块。板块一起涨时，偏强的股票通常更值得盯。

默认基准是 `NASDAQ:SOXX`，一只跟踪费城半导体指数的 ETF，可以理解成「半导体板块整体」。冒号前是交易所，后面是代码。看非半导体股时，可以在设置里改成 `NASDAQ:QQQ`（纳指 100）。

### 6. 近低 / 近高
对应代码：`hh / ll`

最近 20 根 K 线的最低点和最高点，就是图上两条阶梯线，代表眼前的支撑和阻力。价格靠近近高时，站上去结构就会变成「突破近高」；回落时先看均线能不能托住。

## 一起看的顺序

1. 均线 + 结构：判断趋势
2. 量能：确认力量真假
3. 相对强弱：挑出比板块更强的
4. ATR + 近高低：定止损和目标

## 可调参数

| 参数 | 默认 | 作用 |
|---|---|---|
| MA快 / 中 / 慢 | 20 / 50 / 200 | 三条均线周期 |
| ATR长度 | 14 | ATR 计算天数 |
| 对比基准 | NASDAQ:SOXX | 相对强弱的比较对象 |
| 结构回看根数 | 20 | 近高、近低和结构判断的回看范围 |

## 导入方法

1. 打开 TradingView（免费账号即可）和任意股票图
2. 底部点 **Pine Editor**
3. 清空默认代码，粘贴 [`panel.pine`](./panel.pine) 全部内容
4. 点 **添加到图表**；想复用就点「保存」，之后在「指标 → 我的脚本」里选它

表格挡住 K 线的话，把代码里的 `position.bottom_right` 改成 `position.top_right` 或 `position.bottom_left`。
