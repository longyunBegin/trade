# 位置与风险面板（TradingView 指标）

代码：[`panel.pine`](./panel.pine)

## 为什么做这个

[第一性原理面板](../first-principles-panel/) 回答的是「趋势怎么样」。这个面板接着回答三个更贴近下单的问题：

- **现在的位置贵不贵**：离均线多远、在一年里处于高位还是低位
- **谁在用钱投票、会不会要变盘**：量价配合、波动收缩
- **如果进场，止损放哪、值不值**：止损、目标、风险收益比，再加上缺口这种天然的支撑阻力

同样只用价格和成交量，不用 RSI、MACD 这类二次加工指标。两个面板可以同时加在一张图上，这个表在左下角，第一个面板的表在右下角。

## 图上画了什么

- **左下角摘要表**：下面六项的读数
- **红色虚线**：建议止损价
- **绿色虚线**：目标价
- **半透明方块**：还没被回补的跳空缺口，绿色是向上跳空，红色是向下跳空，一直向右延伸，直到被回补才消失

## 六项读法

### 1. 离均线多远
对应代码：`distFastPct / distFastAtr`、`distMidPct / distMidAtr`

显示现价比 MA20、MA50 高或低百分之几，括号里再换算成几个 ATR。

为什么要换算成 ATR：同样偏离 10%，对每天晃 1% 的股票是很远，对每天晃 5% 的股票（比如 SIVE）只是正常。用 ATR 衡量就能跨股票比较。

- **贴近**（≤1 ATR）：回踩到均线附近，通常是位置比较舒服的时候
- **正常**（1–3 ATR）
- **偏离大**（≥3 ATR）：涨得太急，追进去容易遇到回落

### 2. 一年位置
对应代码：`hi52 / lo52 / pos52`

现价落在过去一年最低点到最高点之间的百分之几。0% 是一年最低，100% 是一年最高。

- **≥80%**：近一年高位，强势股常常待在这里
- **≤20%**：近一年低位，可能便宜，也可能是一直在跌
- 中间：中间区域

日线上一年约 252 根 K 线。上市不满一年的股票，就用现有的全部 K 线算。周线图要把「一年K线数」改成 52。

### 3. 量价配合（涨/跌量）
对应代码：`upVol / downVol / udRatio`

最近 20 天里，所有上涨日的成交量加起来，除以所有下跌日的成交量加起来。

- **≥1.2**：买盘主导，涨的时候人多、跌的时候人少
- **≤0.8**：卖盘主导
- 中间：大致均衡

它比只看今天放量缩量更稳，因为看的是一段时间里买卖双方谁更积极。

### 4. 波动
对应代码：`atrHi / atrLo / atrRank`

当前 ATR 在最近 120 根 K 线的 ATR 里排在什么位置。0% 是这段时间里最平静，100% 是最剧烈。

- **≤20%，波动收缩**：价格越走越窄，往往在酝酿一次方向选择，但它不告诉你往哪边
- **≥80%，波动扩张**：正在大幅波动，止损要放宽，仓位要变小

### 5. 止损、目标、风险收益比
对应代码：`stopPx`、`targetPx`、`rrRatio`

- **止损**：取「近 20 根 K 线最低点」和「现价减 2 个 ATR」中离现价更近的那个，括号里写明用的是哪个，以及离现价多少百分比。
- **目标**：近 20 根 K 线最高点。如果已经突破近高，上方没有参考位，就按「止损距离的 2 倍」估算，写作「按 2R 估」。
- **风险收益比**：目标距离 ÷ 止损距离。「1 : 2.5」就是冒 1 块钱的风险，有机会赚 2.5 块。
  - ≥2：划算
  - 1–2：一般
  - <1：不划算，赚的空间还没有亏的空间大

这是机械计算出来的参考，不是买卖信号。

### 6. 未回补缺口
对应代码：`gapBoxes / gapDirs / gapTops / gapBots`

跳空缺口是指今天的最低价高于昨天的最高价（向上跳空），或者今天的最高价低于昨天的最低价（向下跳空），中间那段价格没有成交过。

- 价格之后回到这段区间并穿过它，叫「回补」，方块就会消失。
- 没回补的缺口常常变成支撑（下方）或阻力（上方）。
- 表里写出还剩几个缺口，以及现价上方、下方最近的缺口边缘。

默认只保留最近 10 个。

## 一起看的顺序

1. 先看第一性原理面板：趋势是不是向上
2. 再看这个面板的位置：离均线是否贴近、一年位置在哪
3. 看量价和波动：买盘是否主导、是否在收缩
4. 最后看止损和风险收益比：值不值得做，止损放哪

## 可调参数

| 参数 | 默认 | 作用 |
|---|---|---|
| MA快 / MA中 | 20 / 50 | 计算偏离的均线 |
| ATR长度 | 14 | ATR 天数 |
| 一年K线数 | 252 | 一年位置的回看范围，周线改 52 |
| 量价统计天数 | 20 | 涨跌量的统计范围 |
| 波动比较区间 | 120 | ATR 分位的比较范围 |
| 近高低回看根数 | 20 | 止损和目标用的近高、近低 |
| ATR止损倍数 | 2.0 | 止损离现价几个 ATR |
| 最多显示缺口数 | 10 | 图上保留的缺口方块数量 |
| 显示止损/目标线 | 开 | 关掉就只看表 |

## 导入方法

1. TradingView 打开任意股票图，底部点 **Pine Editor**
2. 新建一个脚本（不要覆盖第一性原理面板），粘贴 [`panel.pine`](./panel.pine) 全部内容
3. 点 **添加到图表**，再点「保存」
4. 如果底部出现 A、B 两根价格轴、线和 K 线对不上：点指标名旁的「…」→「固定至坐标」→ 选 A
